💡 HOW IT WORKS
═══════════════════════════════════════════════════════════════════════════════

VNPAY Payment Flow:

  1. User clicks "Pay with VNPAY"
                     ↓
  2. VNPAY processes payment
                     ↓
  3. Payment successful → VNPAY redirects to /vnpay-return
                     ↓
  4. CheckoutController@vnpayReturn()
     • Validates VNPAY signature
     • Checks response code = "00" (success)
     • Updates order status → "completed"
     • Enrolls user in purchased courses
     • Dispatches SendOrderCompletedNotification job
                     ↓
  5. Queue Processing
     • Job picked up from queue
     • Runs SendOrderCompletedNotification::handle()
     • Creates OrderCompletedMail mailable
                     ↓
  6. Email Sending
     • Loads order with relationships
     • Renders template with order data
     • Sends via SMTP server
     • On failure: Retries 3 times
                     ↓
  7. Email Delivered ✓
     • User receives confirmation email
     • Email contains order details + course access link
     • User can now access purchased courses
